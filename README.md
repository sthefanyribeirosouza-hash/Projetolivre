# Projetolivre
Homofobia no Brasil

📚 Sobre o projeto

Este projeto foi desenvolvido para a aula de Educação Digital com o objetivo de apresentar informações sobre a homofobia no Brasil, mostrando suas diferentes formas, consequências e maneiras de combater o preconceito.

🎯 Objetivos

- Explicar o que é homofobia;
- Mostrar como a homofobia pode acontecer no Brasil;
- Apresentar diferentes formas de discriminação;
- Conscientizar sobre a importância do respeito e da diversidade;
- Incentivar atitudes contra o preconceito.

💻 Tecnologias utilizadas

- HTML5
- CSS3
- JavaScript

🌈 Conteúdo do site

O site apresenta:

- O que é homofobia;
- Homofobia no Brasil;
- Formas de manifestação do preconceito;
- Imagens relacionadas ao tema;
- Vídeo educativo;
- Maneiras de combater a homofobia;
- Quiz interativo;
- Frase de conscientização.
